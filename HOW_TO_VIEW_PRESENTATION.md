# FENG 498 Defense Presentation, how to view it

## Easiest, works on any computer, nothing to install
Download **presentation_share.html** and double-click it.
It opens in your browser with everything built in. No server, no internet, no install.

## Full live 3D experience (the animated version)
1. Download or clone this repository (green "Code" button, Download ZIP).
2. Run the launcher for your system:
   - Windows: double-click **run_presentation.bat**
   - macOS: double-click **run_presentation.command**
   - Linux: run `bash run_presentation.sh`
   If Python 3 is missing, the launcher installs it, then starts a small local
   server and opens the deck.
3. Navigate: arrow keys move, **O** opens the slide overview, **F** fullscreen,
   **N** speaker notes, type a number to jump.
